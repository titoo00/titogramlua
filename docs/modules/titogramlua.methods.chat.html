api.create_chat_invite_link(chat_id, opts)
create an additional invite link for a chat.

Parameters:

  • chat_id number|string unique identifier for the target chat or username of the target channel
  • opts table optional parameters
    • name string invite link name (max 32 characters)
    • expire_date number point in time (unix timestamp) when the link will expire
    • member_limit number maximum number of users that can be members simultaneously
    • creates_join_request boolean true if users joining via the link need to be approved

Returns:

    table,number the response object and HTTP status
api.create_chat_subscription_invite_link(chat_id, subscription_period, subscription_price, opts)
create a subscription invite link for a channel chat.

Parameters:

  • chat_id number|string unique identifier for the target channel chat or username of the target channel
  • subscription_period number the number of seconds the subscription will be active before the next payment
  • subscription_price number the amount of telegram stars a user must pay to be a member of the chat; 1-10000
  • opts table optional parameters
    • name string invite link name (max 32 characters)

Returns:

    table,number the response object and HTTP status
