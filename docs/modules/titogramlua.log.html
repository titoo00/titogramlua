Module titogramlua.log

structured logging and lightweight metrics.

api.log.{debug,info,warn,error} emit through a configurable sink with level filtering; api.metrics holds simple named counters. both are opt-in to configure and have sensible defaults (level 'info', sink = print).

Functions

api.log.sink(level, message) the sink receives (level, message); replace to route logs elsewhere.
api.metrics.all() a shallow copy of all counters.
api.metrics.get(name) read a single counter (0 if unset).
api.metrics.incr(name, by) increment a named counter by by (default 1).
api.metrics.reset() reset all counters to zero.

Fields

api.log.level minimum level to emit; one of 'debug', 'info', 'warn', 'error'.
