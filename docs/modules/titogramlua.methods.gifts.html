api.gift_premium_subscription(user_id, month_count, star_count, opts)
gift a telegram premium subscription to a given user.

Parameters:

  • user_id number unique identifier of the target user who will receive the subscription
  • month_count number number of months the subscription will be active; one of 3, 6, or 12
  • star_count number number of telegram stars to pay for the subscription
  • opts table optional parameters
    • text string text shown along with the service message; 0-128 characters
    • text_parse_mode string mode for parsing entities in the text
    • text_entities table|string a JSON-serialized list of special entities in the gift text

Returns:

  1. table|false true on success, or false on failure
  2. string|table the HTTP status or error details

api.upgrade_gift(business_connection_id, owned_gift_id, opts)
upgrade a given regular gift to a unique gift.

Parameters:

  • business_connection_id string unique identifier of the business connection
  • owned_gift_id string unique identifier of the regular gift that should be upgraded
  • opts table optional parameters
    • keep_original_details boolean pass true to keep the original gift text, sender and receiver
    • star_count number the amount of telegram stars that will be paid for the upgrade

Returns:

  1. table|false true on success, or false on failure
  2. string|table the HTTP status or error details
